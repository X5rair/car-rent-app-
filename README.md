🚗 Car Rent App

Car Rent App is a modern car rental application designed to demonstrate how a real-world vehicle rental service can work.
The app allows users to explore available cars, view detailed information, choose rental dates, and simulate the booking process through a clean and intuitive interface.

⸻

🌟 About the Project

Car Rent App is a portfolio and educational project that focuses on user experience and core business logic of a car rental platform.

The main goal of this project is to showcase:
• application structure
• clean UI design
• basic booking flow
• scalable project architecture

This project does not include real payments or production backend and is intended for demonstration purposes only.

⸻

✨ Key Features

🚘 Browse a list of available cars with images and prices
📄 View detailed information about each vehicle
📅 Select rental start and end dates
📝 Simulate the car booking process
📱 Responsive and user-friendly interface
⚡ Fast navigation and smooth user experience
